# Pacotes integrais

O pacote original contém PDFs, fontes LaTeX e imagens. Os mesmos componentes
estão disponíveis individualmente em `docs/problems/riemann-audit/`, que deve
ser preferido para navegação e histórico de alterações.

Para contornar interrupções de transporte de objetos binários, o ZIP integral
foi dividido em oito partes em `chunks/`. Reconstrua-o com:

```bash
python releases/reconstruct_archive.py
```
