# Submission packages

These are preparation packages, not evidence of journal acceptance.

## `preprint/`

Full LaTeX manuscript suitable for an institutional repository or an arXiv
submission after author metadata, category, endorsement and source checks are
completed. It is the current recommended route.

## `formal_aspects/`

Formal-methods-oriented manuscript source. Before submission, download the
current journal class directly from the publisher and replace the fallback
`article` class. The paper must report actual checker versions and logs.

## `joss/`

Future software-paper package. Do not submit now: JOSS currently requires a
public repository with at least six months of distributed development history,
demonstrated research use, a feature-complete package, and a repository that is
browsable without registration. The current private/new repository fails those
gates.

## Required human decisions

- confirm legal author name, affiliation, ORCID and correspondence email;
- approve all authors and contributions;
- choose repository visibility and archival license;
- obtain a Zenodo DOI for a tagged release when appropriate;
- confirm conflicts, funding, data availability and AI disclosure;
- never submit the same manuscript simultaneously to incompatible venues.
