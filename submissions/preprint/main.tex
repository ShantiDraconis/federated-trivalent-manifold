\begin{abstract}
We present an experimental software framework that represents proposition
status with strong Kleene three-valued logic, evaluates a user-defined complex
action along sampled paths, and exports small formal artefacts to Lean, Coq,
Isabelle/HOL and Agda. The framework enforces an epistemic distinction between
definitions, assumptions, numerical evidence, proof obligations and checked
theorems. A version 4.1 flow controller is audited as a finite state machine:
its accumulator is non-decreasing under explicit non-negative time increments,
and an isolation operator preserves one coordinate while reducing another.
These are properties of the defined model. They are not results about
Perelman entropy, cryptographic security, network availability or any open
Millennium Prize Problem.
\end{abstract}

\section{Introduction}
Cross-domain exploratory models frequently mix analogy, simulation and proof.
The purpose of this artefact is to make those layers machine-readable. The
calculator uses $F,U,T$ for false, undecided and true in a selected theory. The
middle value is epistemic and is not the assertion that a proposition and its
negation are simultaneously true.

\section{Computable model}
For a path $\gamma$ in coordinates $(x,y,z,t,e)$, the illustrative action is
\begin{equation}
S[\gamma]=\int_0^T L(\gamma,\dot\gamma)\,dt+i\int_0^T e(t)\,dt.
\end{equation}
The default calculator uses a composite trapezoidal rule. This produces an
$O(n)$ approximation for $n$ samples; one integrand evaluation is constant
time with respect to $n$.

Version 4.1 defines
\begin{equation}
q(t,e)=\alpha t^2-\beta e^2,\qquad
W_{k+1}=W_k+(q_k^2+\varepsilon)\Delta t_k.
\end{equation}
When $\varepsilon>0$ and $\Delta t_k>0$, exact arithmetic gives strict growth.
For $\Delta t_k=0$ it is non-decreasing. This tautological controller invariant
does not imply resistance to denial-of-service attacks.

\section{Numerical audit}
With $\alpha=0.10$, $\beta=0.10887$, and $\varepsilon=10^{-6}$,
$q(3.15,0.3)^2=0.965211342833$. The previously circulated value $0.9714$ is
not reproduced. For $T=3.155$ and constant $e=0.3$, quadrature gives
$0.605003007857$; adding the endpoint $e(T)$ gives $0.905003007857$. For
$e(t)=0.3e^{-0.2t}$, the corresponding values are $0.617104804182$ and

\section{Formal layer}
Finite truth-table properties are proved separately in four proof-assistant
syntaxes. The Lean module also proves coordinate preservation by the isolation
operator and non-decrease of a rational accumulator under non-negative
hypotheses. Crypto and Riemann statements, where present, are explicitly named
assumptions rather than derived theorems. Full formalization of zeta functions,
PDE regularity, quantum field theory or algebraic cycles is outside the current
artefact.

\section{Operational layer and security boundary}
The Python implementation rejects non-finite coordinates and regressing
timestamps, serializes state changes with a lock, and contains no cryptographic
algorithm. Standard AES key sizes are 128, 192 and 256 bits; the phrase
``AES-512'' is therefore excluded. The abstract teardown theorem proves a
record update, while real ADB teardown still requires runtime observation.

\section{Limitations and research agenda}
The coordinate model, action and comparison metric are proposed definitions,
not canonical bridges among mathematical fields. Future work must publish the
feature provenance for comparison scores, compile all formal artefacts with
pinned toolchains, measure the gateway with a stated hardware/software
protocol, and subject security claims to an explicit threat model.

\section{Remaining behavior audit}
For the positive branch of $q(t,e)^2=1$, the threshold is
\[
t_*(e)=\sqrt{\frac{1+\beta e^2}{\alpha}}.
\]
It equals approximately $3.1640$ for $e=0.1$ and $3.2237$ for $e=0.6$.
These are model thresholds, not measured Quest buffering limits. The defined
zeta force $(\sigma-0.5)^2e$ vanishes at $\sigma=0.5$ by construction; this
does not constrain actual zeta zeros. Likewise, the exponential gauge and
complexity curves are declared decays without cross-domain implications.

For the eight supplied imaginary coordinates, the mean is $30.665$, the median
is $31.675$, the population standard deviation is approximately $9.4639$, and
the mean successive spacing is $4.17$. Every real coordinate is $0.5$ because
the input fixes it so. A second reported spectrum yields effective rank about
$3.44$, but its source matrix is absent and the result is not independently
reproducible. It must not be conflated with $1-\mathrm{Div}$ from the versioned
divergence table, which is not positive definite.

\section{Anomaly-kernel trust boundary}
The exact indicator $\mathbf{1}_{\{\zeta(s)=0\}}$ is a mathematical
definition, not a numerical oracle. In the open critical strip the eta
prefactor is nonzero, but a finite eta sum can only certify non-vanishing when
its magnitude exceeds a rigorous tail bound. Otherwise the status is
inconclusive, never ``zero detected.''

For $S^2=(\alpha t^2-\beta e^2)^2$ the exact partial derivative is
$-4\beta e(\alpha t^2-\beta e^2)$. Hence the proposed $e$ flow is not globally
damping. The verified positive rate is $S^2+\epsilon$ for $\epsilon>0$; it is a
property of the defined scalar model, not operational liveness. No
Rijndael-512 or quantum implementation is part of the artefact.
