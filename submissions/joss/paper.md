# Summary

Federated Trivalent Manifold is an experimental research-software package for
keeping assumptions, numerical models, proof obligations and mechanically
checked finite results distinct. Its browser calculator assigns an epistemic
status from strong Kleene three-valued logic, evaluates a declared numerical
action and exports small specifications for Lean, Coq, Isabelle/HOL and Agda.

# Statement of need

Exploratory models often combine diagrams, simulations and formal notation
without recording which claims were assumed or checked. This package provides
a lightweight status discipline and reproducible examples. It is intended for
teaching, prototyping and auditing conditional specifications. It does not
solve or claim progress on a Millennium Prize Problem.

# State of the field

Proof assistants verify terms inside different logical foundations, while
general document formats and notebooks record computations. This package is a
small interface for generating explicitly classified obligations across
several provers. A mature submission must compare it empirically with related
proof-document and interoperability tools.

# Software design

The Python core implements the finite K3 operations, validated numerical
integration and transparent Jaccard comparisons. Formal files prove finite
truth-table properties. Operational gateway utilities are separated from the
mathematical model. Tests and continuous integration check the executable
invariants, while figures are regenerated from a single script.
