# Omega_p Editorial Package

This folder contains staged, audit-oriented writing assets for the Omega_p program.

## Files

- `technical_audit.md` — consistency and rigor audit checklist.
- `publishable_structure.md` — standard publishable article structure.
- `article_1_existence.tex` — Article 1 draft (ultrapower existence baseline).
- `article_2_finite_confinement.tex` — Article 2 draft (compactifying maps, residues, primary constants).
- `article_2_methods.md` — reproducibility and numerical reporting protocol for Article 2.

## Status policy

Each article must explicitly separate:

1. proved statements,
2. conditional statements,
3. conjectural/deferred statements.

No file in this folder claims a solved Millennium problem.
