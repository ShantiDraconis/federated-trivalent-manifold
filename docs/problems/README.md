# Cadernos formais dos Problemas do Milênio

Estes cadernos comparam o formalismo FTM com as formulações oficiais do Clay Mathematics Institute. Eles são um **programa de redução**, não uma coleção de soluções.

## Regra de conexão

Uma ligação forte entre FTM e um problema \(P\) exige uma tripla
\[
(\Phi,\mathcal I,\mathcal E),
\]
onde:

- \(\Phi\) é um mapa/funtor dos objetos oficiais de \(P\) para objetos FTM;
- \(\mathcal I\) é um conjunto de invariantes preservados por \(\Phi\);
- \(\mathcal E\) é um teorema de equivalência
  \[
  P\Longleftrightarrow P_{\rm FTM},
  \]
  ou ao menos uma implicação cuja direção esteja explicitada.

Sem \(\mathcal E\), existe apenas modelagem. Sem \(\Phi\), existe apenas analogia verbal.

## Níveis de maturidade

- **M0 — vocabulário:** termos semelhantes.
- **M1 — construção:** mapa \(\Phi\) bem definido.
- **M2 — preservação:** invariantes relevantes preservados.
- **M3 — redução:** equivalência/implicação provada.
- **M4 — resultado:** \(P_{\rm FTM}\) resolvido com todas as hipóteses.
- **M5 — validação externa:** revisão especializada e publicação.
