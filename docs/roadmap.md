# Roadmap de pesquisa e falsificação

## Fase A — objeto bem definido

1. Escolher dimensão e categoria de regularidade.
2. Fixar se o grafo é imerso, incorporado, dual a uma decomposição ou parte singular.
3. Provar T0 (descida/colagem).
4. Construir exemplos e contraexemplos pequenos.

**Saída:** artigo de fundamentos independente dos Problemas do Milênio.

## Fase B — invariância e computabilidade

1. Definir movimentos locais entre apresentações.
2. Provar quais invariantes eles preservam.
3. Implementar formato canônico de entrada e validadores.
4. Testar casos cujo resultado clássico é conhecido.

**Falha útil:** duas apresentações equivalentes com invariantes diferentes refutam a invariância pretendida.

## Fase C — uma interface principal

Prioridade recomendada:

1. topologia de 3-variedades/Poincaré como banco de testes;
2. conexões, gauge e descida como teoria estrutural;
3. somente depois, uma interface aberta (Yang–Mills, Navier–Stokes etc.).

Trabalhar simultaneamente nos seis problemas abertos dilui hipóteses e impede auditoria.

## Fase D — pacote mínimo

Cada conjectura ou teorema deve conter:

- identificador estável;
- enunciado formal e quantificadores;
- dependências explícitas;
- prova completa ou marcador OPEN;
- casos-limite e tentativa de contraexemplo;
- comparação exata com o enunciado oficial;
- revisão por especialista antes de alegar avanço substantivo.

## Critérios de interrupção

Uma linha deve ser rebaixada a analogia quando faltar qualquer item:

- mapa definido entre objetos;
- preservação das estruturas relevantes;
- teorema de equivalência ou implicação;
- controle de limites contínuo, termodinâmico ou de refinamento;
- compatibilidade com todas as hipóteses do enunciado oficial.
